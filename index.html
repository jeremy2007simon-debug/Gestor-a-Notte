Con Firebase (gratis) todos los dispositivos que accedan a la web comparten los mismos datos en tiempo real.

Cómo configurarlo:
1️⃣ Ve a console.firebase.google.com → Crear proyecto
2️⃣ Añadir app web → Registrar → Copia el objeto firebaseConfig
3️⃣ Ve a Firestore Database → Crear base de datos → Modo de prueba
4️⃣ Pega el JSON de configuración aquí abajo
